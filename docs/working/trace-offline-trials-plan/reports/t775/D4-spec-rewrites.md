# t775-D4: headed site-reset specs rewritten for the retired reset gates

## Outcome
Done for typecheck and structure audit. 16 specs under `apps/extension/e2e/site-reset/tests/` edited. Nothing run headed (brief). Core is still being built, so every new assertion is written against the design and Core's current source, not observed behaviour. No scripted provider or helper file changed (`change-proof.ts` already had what was needed).

## Common pattern
- Each rewritten spec passes `verify: judge.verify` (`judgeLog()` from `../change-proof`) so the scripted judge records its requests, and asserts `judge.siteChanges()[n]` is defined and its `leftFromEarlier` names the acts left in place.
- `leftFromEarlier` entries carry only `{ did, where }`, no act id. Where a spec needs an act id for a targeted undo (the trial no longer returns `actsToUndo`), the builder sends a claim on an unlisted act: `node(..., { undoes: "act-9999" })`. Per `undo-claims.ts` (act_not_listed branch) the ledger refuses it unrun with `actsToUndo: ledger.inPlace()`, and the page does not move. This is the one new mechanism, in installed-project, photo-looped-other-item, photo-dialog-step and photo-toggle. If Core's final answer shape differs, adjust there.
- `retiredCodesIn(...)` == [] added wherever a retired code was asserted or a trial gate used to be.

## Not verified

## Open questions or contradictions found
- Exploration admission of an unnamed lasting press (old `create_baseline_required` / `reset_witness_required`) is now asserted nowhere, because pressing it would break the spec baselines. A dedicated small spec could press it and assert `ok` plus the declared consequence; I did not add one (outside the "rewrite" brief). Say if wanted.
- office-buy-now / cross-brief: Buy Now leaves the cart unchanged, so the part's proof would be `no_change`, which per the design turns a judge yes into `unknown`. The specs still expect `yes`. If D1 enforces that for parts with a typed effect, these two will need a declared `effect` or a different oracle.
- Test titles in office-buy-now ("settles ... on Core's own look") and office-address-confirm describe the retired flow; I left the titles (they key reports) but they are stale.
