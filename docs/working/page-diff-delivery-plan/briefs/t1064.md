# Brief t1064: the Lab carries no call count

**Goal.** No count of calls ends or invalidates a run. This is the user's rule, in AGENTS.md "No arbitrary limit
ends or resets a run". Core removed its call counts in t1056 (fluxiq 0.54.30):
- `AUTOMATION_STUDIO_LLM_RUN_CALL_BACKSTOP` is deleted;
- `maxCallsPerRun` is gone from the resolution;
- the Studio ledger strips any spread `maxCallsPerRun`.

The Lab still carries its own counts, and its prelude build now fails: `packages/test-runner/src/live-llm/tests/live-llm-plan.test.ts:7`
imports the deleted constant. Remove the Lab's call counts at the root:

- **`packages/test-contracts/src/llm.ts`.** Remove `LLM_LAB_MAX_CALLS_PER_RUN` (250), and remove `maxCallsPerRun` from the budget types, from
  `DEFAULT_LLM_LAB_BUDGET` (26) and from the dry budget. Where a run token bound was derived as
  `maxTotalTokensPerRequest * maxCallsPerRun`, drop that derivation; the dollar ceiling bounds a run.
- **`packages/test-contracts/src/llm-validation.ts`.** Remove every `maxCallsPerRun` rule:
  - the range check;
  - "must not exceed maxCallsPerRun";
  - "retries must fit within maxCallsPerRun";
  - "must equal 0 in deterministic-dry mode".

  Records already on disk may still carry the field, so accept it as an optional, ignored key. Never require it.
- **`packages/test-runner/src/live-llm/live-llm-plan.ts`.** Remove `CORE_MAX_CALLS`, `declaredCalls` and the `--llm-max-calls` flag. An
  operator who still passes the flag gets a clear refusal saying no call count exists and the purse
  (`--llm-max-cost-usd`) bounds a run.
- **`packages/test-runner/src/existing-fluxiq-control/adaptation-evidence-loop.ts`.** Remove the upper bound on a record's
  provider call counts (`> LLM_LAB_MAX_CALLS_PER_RUN`). Keep only the shape checks: a non-negative whole number, and a
  total not below the round's count.
- Anywhere the Lab or its harness passes `maxCallsPerRun` or a call count into Core's resolution, a Flow's settings
  or a profile: stop. Find these with grep across `packages/`, `scripts/lab/` and `domain/src` (non-test).
- Update the tests that pinned these, including live-llm-plan, demo-llm-profile, existing-fluxiq-control and the
  test-contracts tests, and `docs/architecture/testing-facility.md` where it describes a call cap.
