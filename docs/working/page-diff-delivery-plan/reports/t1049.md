## What changed and why

### The setting and its endings (Core, `packages/fluxiq/src/runtime/`)

- `llm/loop-configuration.ts`: `maxStepsWithoutProgress` removed from the loop input and from `EvidenceLoopLimits`,
  with `redirectAtStepsWithoutProgress`; the `limits.max_steps_without_progress` and
  `limits.max_steps_without_progress_agrees` checks removed. `maxUnusableDecisionsInARow` now defaults to
  `min(12, maxIterations)` and is checked from 1 (it was floored at the removed guard). `uncounted` no longer lists it.
  `unusableDecisions.maxConsecutive` is kept, `@deprecated` and read by nothing (see Open questions).
- `agents/progress/no-progress.ts` (the generic tracker): `max` and `reached()` removed; `redirect` fires from
  `redirectAt` on every further step with no upper stop; the snapshot has no `maxStepsWithoutProgress`.
- `llm/evidence-progress/no-progress.ts`, `redirect-facts.ts`, `stall-redirect.ts`: the redirect has no
  `maxStepsWithoutProgress` / `stepsLeftBeforeStopping` and no "N more step(s) without progress stop this build /
  this round ends / this exploration stops" sentence in any mode (draft, candidate, planning). `freshRoundFollows`
  removed (it only chose which stop sentence to say). The instruction now ends with the way out.
- Endings removed (each was `noProgress.reached()`): `evidence-loop.ts` (unusable decision, a run call with no news),
  `decision-handlers/amendment.ts` (an edit that changed nothing or toggled), `decision-handlers/answered-request.ts`

  refused-repeat.ts` (the `|| reached()` half of the refused-repeat stop; the three-in-a-row refused-repeat rule stays),
  `prior-nodes/loop.ts` (a batch that executed nothing, and the admission's `stopped`).
- Model-facing feedback (`unusable-decision.ts`, `tool-failure.ts`, `evidence-loop/answered-request.ts`,
  `draft-amendment-feedback/feedback.ts`, `evidence-loop/unreadable-reply.ts`, `decision-handlers/answer-check.ts`):
  `maxStepsWithoutProgress` dropped from every note; `stepsWithoutProgress` stays (it is what the model is told it
  repeated). Untrue words fixed: "Failures count toward stopping this exploration" and "toggling a step counts toward
  stopping this exploration".
- `loop-limits/evidence-loop.ts`: `AUTOMATION_STUDIO_LLM_EVIDENCE_LOOP_MAX_CONSECUTIVE_UNUSABLE_DECISIONS` (read by
  nothing) deleted; `AUTOMATION_STUDIO_LLM_EVIDENCE_LOOP_DEFAULT_MAX_STEPS_WITHOUT_PROGRESS` kept `@deprecated`, read by
