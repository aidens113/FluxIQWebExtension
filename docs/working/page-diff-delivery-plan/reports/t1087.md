## Anthropic limits relied on

From the live structured-outputs page (`platform.claude.com/docs/en/build-with-claude/structured-outputs`, "Explicit limits"). The bundled skill files do not state these numbers.

- "Strict tools per request | 20 | Maximum number of tools with `strict: true`."
- "Optional parameters | 24 | Total optional parameters across all strict tool schemas and JSON output schemas. Each parameter not listed in `required` counts toward this limit."
- "Parameters with union types | 16 | Total parameters that use `anyOf` or type arrays (for example, `"type": ["string", "null"]`) across all strict schemas."
- "These limits apply to the combined total across all strict schemas in a single request."
- Also: `anyOf` may not sit in the same schema object as `type` or `properties`, and the platform adds internal limits ("Schema is too complex for compilation", 180 s compile timeout).
- The nullable members use `type: ["string", "null"]`, the documented form, plus `null` in the enum.
