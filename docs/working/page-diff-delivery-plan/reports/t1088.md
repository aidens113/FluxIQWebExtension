## What changed and why

- `flow-run/stop-observed.ts` (new). At a replay stop whose last unresolved failed attempt is `core.step.effect_not_seen`, it observes the page once (`observeAutomationStudioRouteState`) and asks the stopped step's recorded effect through the existing port `automationStudioRouteEffectHolds` (the host's `routeEffectHolds`, the same call the router's `effectHolds` makes). It answers `holds` (with the plan key of the step after it) or `page` (with the page named by its site through `automationStudioActivityPageName`: never a word of the path). No wait, no retry.
- `flow-run/flow-run.ts`. `run()` takes an optional `fromNodeKey` (the existing from-step seam of `runAutomationStudioDetachedCandidate`, t804) and returns the host it ran with. New `handedOver()` runs after the first run:
  - Effect holds: the run goes on in the same attempt from the next step. The stopped step is never run again, so a lasting act is not repeated. The stopped attempt is marked `stateHeld` (the marker the engine's own `skip_satisfied_node` rung uses), so readers see it as done. The two traces are merged. A from-step run ends `executor.graph.unvisited_nodes` for the steps before its start; when the merged attempts leave nothing unvisited (`hasUnvisitedAutomationStudioNodes`) that ending is the Flow's end.
  - Effect not on the page: the outcome carries `pageNow` (the observed page's name).
  - A step log note is written when the run goes on.
- `flow-run/steps-ran.ts`, `flow-run/outcome.ts`. `Ended` gains `resumedPast` and `pageNow`; the passed step that was resumed past says so (`happened`: its effect "was there when the run stopped, so the run went on from the next step"); `failing` gains `pageNow`.
- `attempt/round-note.ts`. A failing step with `pageNow` is told "The page was read again as the run stopped, and it does not show what this step brought; it shows <site>. Look at it as it is now, fix that step, then run forward. ..." instead of "The page is where it left it". Other failures keep the old sentence.
- `runtime/automation-activity/wording/index.ts` (outside the owned list; one line). Exports the existing `automationStudioActivityPageName` from the barrel, which the structure audit's import rule required. Flag for the lead.
