   filters on the envelope kind) reads nothing back over real SQLite. B1 works around it with an adapter
   in `provisioning/service/envelope-kind-repository.ts`. B3 and C will meet the bug again when they open
   an `IamStore` on SQLite: fix `IamRecords` to tell kinds apart by id prefix.
2. **Single-tenancy workspace id.** It is `"workspace-main"` (override with `FLUXIQ_WORKSPACE_ID`),
   because no document defines one. Confirm it, or let lane C pick.
3. **Contract gaps.** These are not changed; contracts are frozen:
   - The listener answers an unexpected failure with 500 `internal_error`, a code the contract lacks.
   - No error code fits identity-access refusing to disable, delete or demote the last admin, so `run`
     throws there and the listener answers a generic 500.
4. **Admin revoke takes a raw session id, but the panel shows only digests.** In practice an
   administrator cannot revoke another user's session, so it needs a revoke-by-digest admin path.
   Separately, the secret-keys `revokeSessionUnlock` lets anyone who holds a session id drop that
   session's unlock (lane C owns secret-keys).
5. **Size.** `IdentityAccessService` is at 40 methods, the audit's limit, and `service.ts` is at 794
   of 800 lines. The next addition there needs an extraction first.
6. **Routes still to wire.**
