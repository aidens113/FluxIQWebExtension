# t788-C2 report: IAM store structure-audit fixes

## Outcome
Done. No FAIL lines for platform/iam/store remain; the 19 tests pass; tsc reports no errors.

## What changed and why
Root: packages/fluxiq/src/platform/iam/store/. The 48-method IamStore became a 35-method facade (iam-store.ts) over collaborators that share an IamStoreScope.
- context/: change-context, emit-change, principal-ref, store-options, store-scope (IamStoreScope: workspaceId, records, now, principalFrn, policyFrn, audit)
- repository/: record-repository (types), records (IamRecords)
- errors/: store-error, store-error-code
- limits/: max-attached-policies, max-policy-versions
- assert/: not-predefined, policy-name, segment
- parse/: policy-document, principal-frn
- policies/: policy-store (IamPolicyStore), policy-users
- attachments/: attachment-store, inline-store, boundary-store, guardrail-store, remove-principal-state
- principals/: group-store, role-store, service-identity-store, require-principal, type-label
- resolve/: policy-resolver (IamPolicyResolver.resolve = resolvePolicySet)
- records/: stored-record types with the iam-/stored- prefixes dropped (attachments, boundary, group, guardrails, inline-policy, policy, policy-version, role, service-identity)
- tests/iam-store.test.ts: kept (it tests the facade end to end); only its imports changed.
Every directory has an index.ts barrel. No directory has 3 or more files sharing a prefix.

## Exported API
store/index.ts still exports every previous name: IamStore, IamStoreOptions, IamStoreError, IamStoreErrorCode, IamChangeContext, IamRecordRepository/Envelope/Scope, IAM_MAX_ATTACHED_POLICIES, IAM_MAX_POLICY_VERSIONS and all IamStored* / IamPolicyVersion types.
New exports: IamStoreScope, emitIamChange, IamPrincipalRef, IamRecords, IamPolicyStore, policyUsers, IamAttachmentStore, IamInlineStore, IamBoundaryStore, IamGuardrailStore, removePrincipalState, IamGroupStore, IamRoleStore, IamServiceIdentityStore, requirePrincipal, principalTypeLabel, IamPolicyResolver, IamPolicyResolverSources.
IamStore public method names and signatures are unchanged (they now return the collaborator's promise).
