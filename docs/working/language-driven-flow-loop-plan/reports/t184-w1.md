## What changed and why

- `everything-store/pages/orders-today.ts` (new), `pages/confirmation.ts`, `pages/index.ts`, `workflows/purchase.ts`: D1. The confirmation page described only the order it confirmed. A run that spent the money twice therefore ended on a page every fact accepted. The fix is a statement on the page, not a looser oracle.
- `everything-store/pages/cart/main.ts`, `workflows/add-to-cart.ts`: D3. Only the Saved for later list tells a save from a delete.
- `everything-store/live-tasks.ts`: D2. I changed the instruction wording only. The dataset was right, and the words asked for more than it holds.
- `everything-store/tests/scenario.test.ts`: added three unit tests (D1, D2, D3) and a `failingFacts` helper that reads facts by test id.
- `everything-store/tests/honest-paths.test.ts`: added the deal-wheel honest browser path (D4).
