## Open questions or contradictions found

1. The creation lane judges dataset tasks by records only (`packages/test-runner/src/flow-lane/creation/lane.ts`: `oracleHeld = extraction ? createdFlowDatasetHolds(...) : checkFinalState()`). A state-changing dataset task therefore has its side effects checked only through what the Flow reads back. D2 and D4 close that gap through the wording. A Flow that fabricates its output from a pre-computed list without reading the page is still not caught. Recommendation: have the lane also check `finalState` for dataset tasks, and give confirm-requests a server-side fact.
2. photo-social-moon-jar-price, and move-open-day without a grant, are judged `expected-dataset`, so without `--llm-permit` they can only fail. Per their comments, the expected outcome there is a permission request, which this row format cannot express. The supervisor should run them with the grant, or treat a no-grant `permission_required` as the pass.
3. The Framelight DM composer also sends on Enter. A Flow that types the question followed by Enter reaches the send without a press node, so the send_or_publish consequence may never be declared. This is real site behaviour, not a fixture bug. Flagged for the permission lane.
4. The instruction text for confirm-requests and move-open-day changed, so their sha256 changed. Any earlier measurement of these two rows is not comparable.
