### Departures from the owned paths (forced by the structure audit)

- `commands/` already holds 25 source files, which is the `directory-files` limit. A new file there fails the audit.
- A `commands/<sub>/` directory would be 10 path segments, over the `maxPathSegments: 9` limit.
- Importing a file from that subdirectory past its barrel would be a ratcheted barrel skip.
- Putting `announcement.ts` behind a barrel that create-here also imports would add a load-time cycle
  (catalog -> create-here -> announcement -> catalog) and a TDZ ReferenceError when the catalog's Map is built.
- So `site-name.ts` went one level up, into `conversations/`. Commands and respond import it as `../site-name.ts`, which the audit
  allows because the importer is inside that directory. The announcement lookup went into respond.ts.
- I did not add `site-name.ts` to `conversations/index.ts`, which I do not own. Nothing outside the directory uses it.
