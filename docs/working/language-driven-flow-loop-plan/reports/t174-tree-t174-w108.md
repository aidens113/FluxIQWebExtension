## What changed and why

- **D2, `activity/wording/action.ts`**: a navigate is now named by its site, never by a path or address.
  `https://www.amazon.com/s?k=x` gives `Opening “amazon.com”`. An IP, localhost, `[::1]`, `~` or `~/` gives
  `Opening the start page` (no quotes, so it is not read as a control). A path with no site (`~/ip/x`, `/cart`), a
  non-http(s) address, or anything that is not an address gives `Opening a page`. I removed the old path code
  (`addressPath`, `decoded`, `TOKEN_SEGMENT`, `MAX_PATH`). I did not import `conversations/site-name.ts`. It returns
  "the page you had open" for IPs, it cannot read the relative forms, and it would make `activity` import
  `conversations`. The host logic is 10 lines, private to this file.
- **D5 Core side, `activity/wording/action.ts` `elementName`**: an element's `label` is now read before
  `accessibleName` and `visibleText`. Step 0044 and playback 0060 carried `element: { label: "Quantity" }`, so they now
  read `Typing into “Quantity”` (and `Typing "3" into “Quantity”` when the domain supplies the words). An id-shaped
  label is still dropped and falls back to the accessible name. Typed text is still never read from the parameters.
- **D4, `activity/wording/draft-edit-refused.ts`**: a refused edit is now a neutral line with one reason (the first
  the draft gave) and no model summary. Example: `Didn't change the Flow` / `That step already does that.` Unknown
  reasons give `The Flow is as it was.` The `summary` parameter is now an optional `_summary`, so the
  `activity/draft-edit.ts` caller compiles unchanged.
- **D9, `activity/build.ts`**: the done label is now `Your Flow is ready`. The detail title stays `Build finished`,
  because `ui/activity-action` reads it.
- **Cause 6, `llm/draft-amendment-feedback.ts`**: new `notRunYet()`. A `no_such_step` refusal for the next free
  number (max position + 1, or 1 for an empty draft) now carries `next`: "There is no step N yet: a step enters the
  draft only by running. Run that action first as a call with add true (and its act, if it does one), and it becomes
  step N; do not amend it before it has run." The existing `NEXT_INSTRUCTION` follows from it. Any other number is
  unchanged.
- **R3, `llm/step-log/answer-step.ts`**: `AutomationStudioLlmStepLogAnsweredRow` gains `amendmentCheck?: unknown`.
  When an amend_draft row carries it, `result.json` writes it word for word as `told`.
