# Worker briefs — Week 1

One file per wave. Each holds the briefs the senior supervisor agent
dispatched for that wave, in the protocol's brief format: the task, the files
the worker owns, the files it must not touch, and the checks it must run. They
live here rather than in the plan's `Worker Briefs` section because the plan
sits at its compaction threshold, and they are kept as written, so a brief
still records what a worker was and was not asked to do.
